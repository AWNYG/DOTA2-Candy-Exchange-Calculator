ExchangeRule.txt文件格式

CandyType:5          //设置糖果种类，A、B、C、D、E....依此编号  
Rules:4              //设置糖果交换规则数量  
Maximum:30           //仓库上限  
0;2;0;2;0	3;0;1;0;0  //规则1  
1;0;2;0;0	0;1;0;0;2  //规则2  
0;0;0;1;1	1;0;1;0;0  //规则3  
0;0;2;2;0	0;1;0;0;3  //规则4  

Inventory_Target.txt文件格式  

6;2;0;2;2            //库存  
2;0;4;0;2            //兑换物所需糖果量  

输出格式  
例：2 -> L(A->C) -> 4  
先执行交换规则2，再执行常驻交换，3个A换一个C，最后执行交换规则4
